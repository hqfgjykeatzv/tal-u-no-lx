## Overview

TAL-U-NO-LX faithfully emulates the Roland Juno-60 synthesizer, modeling its DCO oscillator, HPF/LPF filter, and the distinctive bucket-brigade chorus that defines the Juno sound.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **TAL-U-NO-LX** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Juno-60 Model** | Faithful DCO and analog filter emulation matching hardware measurements |
| **BBD Chorus** | Two-mode bucket-brigade chorus matching Juno-60 chorus circuit |
| **Patch Memory** | 128 patch memories with instant recall and MIDI program change |
| **Arpeggiator** | Four-mode arpeggiator with latch synced to host BPM |
